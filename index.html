    • Yocto
      • Overview: Key Yocto terms and definitions (build directory, package, ...).
    • Bootloader

    • ES Devices

    • Docker: Placeholder for Docker notes (no content yet).
    • Linux PTP: Network synchronization with IEEE 1588 PTP and ITU-T G.8260 on Linux.
    • DPDK: Placeholder for DPDK notes (no content yet).
    • Network Block Device: Introduction to and usage of Network Block Device for remote block storage.
    • Tips: Practical tips such as SSH options for remote control.
    • Projects: projects are implemented in several platforms.
      • Zynq: Projects on Zynq boards such as Zedboard and Picozed.
      • IMX8: Placeholder for IMX8 projects (no content yet).
      • Raspberrypi 3B: Raspberry Pi 3 Model B links and notes on porting Linux.
    • Linux General
      • Unsorted: Unsorted Linux notes such as update-rc.d and SUSv3.

    • Linux Device Driver
      • Overview: Overview of general concepts of Linux Device Driver.
      • Kernel Module: Kernel module basics and printing logs with printk and dev_* functions.
      • Platform Device: Placeholder for platform device driver (no content yet).
      • I2C Subsystem: I2C bus and the Linux I2C platform driver model.
      • SPI Device: Developing SPI device drivers in the Linux kernel.
      • SPI Device Advance: Advanced SPI topics: extending chip-select signals and SPI GPIO (outline only).
      • GPIO: The Linux GPIO subsystem from the driver perspective.
      • UART: Serial (UART) programming in userspace with reference materials.
      • JESD: Placeholder for JESD notes (no content yet).
      • Audio: Audio in Linux: ALSA architecture and concepts.
      • PCIe: Placeholder for PCIe notes (no content yet).

      • Kernel Data Structure: Kernel data structures such as the list_head linked list.
      • Kernel Space, User Space Interfaces: Reference link on kernel space and user space interfaces.
      • FTrace: How to use ftrace to debug the kernel, from a real synchronization bug.
      • Dynamic Debug: Enabling and disabling kernel debug messages at runtime with dynamic debug.
